KeepLid privacy policy

Last updated: November 8, 2026 · Version française

In short

KeepLid does not collect, transmit or sell any data. The app runs entirely on your computer: it makes no internet connection and uses no telemetry, no advertising, no account and no third-party service.

Data handled on your computer

To work, KeepLid only stores the following files in its local data folder (%LOCALAPPDATA%\KeepLid\, redirected by Windows to the app's private folder):

  • settings.json: your preferences (durations, thresholds, shortcut, favorite process names);
  • restore.json: temporarily, the original values of the "lid close" setting so they can be restored; this file is deleted as soon as they are;
  • log.txt: a technical log (1 MB max, rotated) of the app's actions (turn on/off, restore, errors), useful if you ask for support.

For the "until a process ends" feature, KeepLid reads the names of running processes, in memory only and only to know whether the chosen process is still running. This list is neither stored nor transmitted. KeepLid also reads the battery and lid state for its safety limits.

These files never leave your computer. You can look at them at any time (Settings › "Open the log"); they are removed when you uninstall the app.

System settings changed

When you turn on the lid mode, and only if Windows allows it without administrator rights, KeepLid temporarily changes the "When I close the lid" action of the active power plan. The original value is saved before the change and restored automatically. KeepLid changes no other setting, never asks for administrator rights and does not write to the registry.

License and Microsoft Store

The license check (purchase or trial) is performed by Windows and the Microsoft Store, under the Microsoft Privacy Statement. KeepLid receives no personal information in the process, only the license status.

Links
